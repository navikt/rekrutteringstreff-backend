## Kodeendringer

- JacksonConfig (api, minside): `jacksonObjectMapper().apply { ... }` → `jacksonMapperBuilder()`-kjede. `WRITE_DATES_AS_TIMESTAMPS` → `DateTimeFeature`, `READ_UNKNOWN_ENUM_VALUES_AS_NULL` → `EnumFeature`. JavaTimeModule fjernes.
- aktivitetskort Jackson.kt: `.configure(...)` → builder.
- TestRapid: `.registerModule(JavaTimeModule())` → fjern.
- `JavalinJackson(mapper)` → `JavalinJackson3(mapper)` i 3 App.kt.
- ExceptionMapping: `JsonParseException`/`JsonMappingException` → `StreamReadException`/`DatabindException`.
- `asText()` → `asString()`, `textValue()` → `stringValue()` osv. (~400 treff på tvers av 75 filer, mest tester).
- **`JsonNode.map {}`-skygging (Jackson 3.1+)**: 1 i main (`KandidatlisteLukketLytter.kt:51`, `packet["fnrFikkIkkeJobben"].map { it.asText() }`), ~33 i tester. → `.values().map {}` + javap-sjekk.
- Ingen egendefinerte (de)serializere, ingen æøå-prefiksede properties funnet. `@JsonTypeInfo(DEDUCTION)` i HendelseDataDto.

## Stille endringer i standardoppførsel som påvirker wire-format

- `SORT_PROPERTIES_ALPHABETICALLY` på: feltrekkefølge i JSON (API-svar, Kafka-meldinger, DB jsonb-kolonner) endres.
- ~~aktivitetskort kan få endret datoformat~~ Rettet i kvalitetssikringen: `tilAkaasJson` gjør datoer om til strenger med `.toString()` før serialisering, så formatet påvirkes ikke av Jackson-versjonen.
- `FAIL_ON_NULL_FOR_PRIMITIVES` på, `FAIL_ON_TRAILING_TOKENS` på.
- Enum via `toString()`: ingen enum overstyrer toString (verifisert), lav risiko.
